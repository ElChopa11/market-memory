# mm-source-health

Standing data-quality / source-health report for the Data & Market Memory Desk.

- CLI: `lab data source-health` (alias `lab dq report`)
- Artifact: `ops/reports/source-health/YYYY-MM-DD.md`
- Read-only public probes + env completeness. No trading, no secrets in git, no market prints.
