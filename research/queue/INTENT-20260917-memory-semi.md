### Falsifiable differentiation (must clear before any thesis)

| Claim | Falsifier (examples) |
|---|---|
| **Memory $ content per AI accelerator** rises or stays elevated (HBM attach / stack / ASP) independent of GPU unit upside already in NVDA | Accelerator BOM teardowns / vendor disclosures show HBM $ share **falling** or HBM ASP **cutting** while GPU ASPs hold |
| **Memory pricing / utilization** (HBM + server DRAM) stays tight vs inventory rebuild | Contract ASP series (DRAMeXchange-class) and company inventory-days roll over while hyperscaler GPU guides still “fine” |
| **Capacity bottleneck** is memory wafers / advanced packaging, not only GPU supply | HBM/DRAM capacity additions + yield recovery **outpace** accelerator demand; spot–LTA gap collapses |
| **Idiosyncratic memory-cycle alpha** exists after hedging AI-infra beta | MU / SNDK / SKHY **fail to outperform** a beta-matched NVDA+AVGO (or SMH) basket on the memory-specific checkpoints below |

**What this is not:** a second long of “AI chips / semis beta.” If the only story is “AI demand → everything semi up,” Skeptic should **reject** promotion — that exposure is already expressed by **NVDA (primary)**, **AVGO (satellite)**, and **SMH (watch-only basket)**.

**Rejection-quality priors (front-loaded):**

1. **Crowded HBM / memory narrative** — street and media already frame memory as the AI bottleneck; late intent, not early discovery.
2. **Already-priced AI memory boom** — public tape and megacap memory re-rating (including Micron’s public AI-memory investment framing) reduce “mispricing” claim; need **incremental** evidence, not vibes.
3. **China / export controls** — license, end-market, and equipment constraints can break both bull (denied demand) and bear (forced undersupply) stories; must be checkpointed explicitly.
4. **Inventory cycle** — memory has a long history of ASP spikes → overbuild → glut; WIP/inventory up under LTAs can look “strong” until it isn’t.
