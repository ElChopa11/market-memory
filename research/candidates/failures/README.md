# Candidate failures

Archive of **what does not work**. This folder is a learning record, not a recycle bin.

A candidate moves here when:

- the source claim cannot be restated with sample, window, instrument set, cost model, and split method (**REJECT** at intake), or
- a Quant validation study records study-verdict `REJECT` or a Skeptic FAIL-archive on the *study* (not an instrument Quant Board card).

## Rules

1. **Do not delete.** Failed cards stay queryable. Same spirit as rejected theses: the record remains.
2. **Do not silently reopen.** Revival requires new evidence (new window, new instrument set with PIT tape, new cost model, or a restated claim) and a new candidate id or a dated amendment. Copying the file back to `research/candidates/` without that evidence is forbidden.
3. **Keep the lesson.** Each archived card must state why it failed: look-ahead, survivorship, `n < min_sample`, cost-destroyed expectancy, unfalsifiable slogan, or split leakage.
4. **No sizing. No scan-gate.** Failure is not a license to promote, size, or “try it live.”
5. **Provenance stays honest.** Retail video / Substack / Reddit remains `n=unknown` even after failure. A viral clip is not a post-mortem sample.
