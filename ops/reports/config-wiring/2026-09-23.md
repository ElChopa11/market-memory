## Method

For each file, Python under `packages/`, `apps/`, `scripts/`, and `tests/` was searched for the relative path and the filename. A hit counts as a **load** only when that code opens the file (`read_text`, `read_bytes`, or `yaml.safe_load` on the path). These do **not** count:

- Docstrings, comments, and queue/runbook mentions.
- `Path.is_file()` existence checks.
- A path constant that no function passes to a reader.
- A shared filename stem that belongs to a different file (`calendar.yaml`, `desk.yaml`, `watchlist.yaml`).
- Candidate ids `C-001` / `C-002` / `C-003` cited by base-rate code. Those strings are not reads of `config/candidates/C-00N.yaml`.

`loaded?` in the table:

| Value | Meaning |
|---|---|
| **yes** | A package, app, or script opens the file and uses the parse. |
| **test-only** | A test opens the file. No runtime loader. |
| **no** | Nothing opens the file. |
