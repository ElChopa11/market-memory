## Method

| # | Criterion | How it is scored here |
|---|---|---|
| 1 | **Point-in-time integrity** (top) | Can Memory set `as_of_knowledge = ingested_at` without look-ahead? Are vintages / revisions timestamped? Delisted retained? |
| 2 | Geo from Australia | HTTP class from this egress on 2026-09-18 (451/403/404 vs 200). |
| 3 | Licence / ToS | Quoted clause. Telegram reprint of a figure ≠ syndicating a feed. Commercial-use and “personal use only” called out. |
| 4 | Coverage vs named gap | Liquidation, CVD, basis, ES/NQ, VIX term, US calendar, filings, earnings confirmed-vs-est, 5y daily, delisted. |
| 5 | Rate limits / cost @ ~40 symbols, 2 scans/day | ~80–200 GETs/day unless bulk. |
| 6 | Reliability | Official SLA vs hobby API vs known cloud-IP blocks. |
| 7 | Integration cost | S / M / L against current `mm_ingest` / Pulse / Polygon lock. |
| 8 | Overlap | Does it duplicate HL `/info`, Polygon equities, CoinGecko, FRED, fixture calendar? |

**Telegram rule used below.** A private research brief that cites an attributable official print is not the same as redistributing a vendor’s API as a product. Vendors that forbid display, redistribution, or any non-personal use are **reject** for Telegram even if the lab could store internally. Vendors that allow research/display with attribution are **adopt/trial** with the attribution lock named.

**PIT rule used below.** Lab knowledge clock stays `as_of_knowledge` lockstep with `ingested_at` (never `published_at` / `market_time`). A source that restates history without vintages is weak even if geo and price look fine.

## Top-3 adopt first (and what each replaces)

### 1. FRED env + ALFRED vintages (Treasury/Fed series only) — IMP-022

**Replaces:** `SRC-FRED-MISSING-ENV`; Pulse/macro **rates** slot; later curve (`DGS2`, `T10Y2Y`) and credit (HY OAS) when series are public-domain / citation-required.

**Why first.** The adapter, runbook, and source-health probe already exist. The failure class is `missing_env`, not geo or ToS. Cost $0. PIT is the best in this list (ALFRED vintages).

**Operator steps (no code in this PR):** Principal (not Don) creates a personal FRED API key at the St. Louis Fed, sets `FRED_API_KEY` in gitignored `.env` and optionally CI secrets, confirms with `lab data source-health --no-db`. Never commit the key. Don does not decide secrets.

**Telegram:** “Source: Board of Governors of the Federal Reserve System (US) via FRED®”. Required disclaimer if the API is cited: *This product uses the FRED® API but is not endorsed or certified by the Federal Reserve Bank of St. Louis.* Skip series whose FRED copyright chip is **Copyrighted: Pre-approval required** (typical for CBOE VIX and S&P 500). FRED ToS also forbids using FRED content to train LLMs — keep FRED rows out of prompt corpora.

### 2. Binance market-data-only hosts — IMP-023

**Replaces:** `api.binance.com` HTTP **451** from AU/cloud; half of the spot cross-check; the need to *buy* CVD.

**Why second.** Official Binance FAQ hosts: REST `https://data-api.binance.vision` (same public paths as spot market-data) and bulk `https://data.binance.vision`. Probed **200** here while `api.binance.com` and `fapi.binance.com` returned **451**. `aggTrades` on vision is enough to compute **CVD** (taker-buy vs volume) for BTC/ETH at two scans/day. Monthly/daily zip klines are the cheap Quant crypto history path.

**Does not replace:** USD-M *live* futures REST (still 451). HL remains the perp structure source. Do not add Bybit (403) as a fallback.

### 3. Official filings + Treasury + CB statistics — IMP-024

**Replaces:** fixture-only economic calendar as the *only* live path; missing **confirmed** earnings/filings; paid calendar/news vendors; a chunk of “US calendar NO DATA”.

**Why third.** EDGAR submissions JSON, daily/full indexes, and `data.sec.gov` are public records (10 rps, declared User-Agent). 8-K item 2.02 is **confirmed** earnings; Street consensus is vendor IP (reject Finnhub/FMP/Benzinga for Telegram). Treasury Fiscal Data licence is the cleanest redistrib grant in this evaluation. ECB SDMX already 200 from this egress; BoE/RBA tables exist as official statistics.

**Does not replace:** ES/NQ futures, VIX term structure, or CoinGlass-style liq heatmaps.

## ES / NQ + VIX term structure without a CME licence

**True ES and NQ futures cannot be adopted without a CME Information License.** Redistributing delayed CME futures as a data feed is **Delayed Distribution $21,840 per year per DCM** on the CME Group Fee List effective 1 January 2026 (plus any vendor: Databento usage and/or Polygon Futures Advanced ~$199/mo, and non-display ILA if software consumes the tape). A non-pro *display* bundle at a few dollars/month is not an API, not machine-readable, and not Telegram-redistributable.

**Lawful substitutes (no CME):**

1. Leave ES/NQ **unavailable** (current honest path after Stooq 404). Prefer this over a proxy that is mislabelled as ES/NQ.
2. If Principal expands membership: **SPY / QQQ** (and optionally `SMH` already watch-only) via **existing Polygon** as cash-index *proxies*, labelled as ETF last, never as ES/NQ.
3. USD: FRED `DTWEXBGS` (broad dollar), not DX.f.
4. Vol **spot close**: only if the FRED VIXCLS copyright chip allows citation-required use; otherwise leave VIX unavailable rather than scrape Cboe JSON (403/ToS-grey).
5. **VIX term structure (VX futures):** **NO DATA** without a CFE/Cboe licence. Unlicensed `cdn.cboe.com` JSON is reject. VIXY/VXX ETFs via Polygon are not a term structure.

**Licensed cost (if Principal later wants the real thing):** ~USD 22k/year delayed *distribution* per DCM, or a negotiated research/non-display ILA (market reports often ~$290–$427/mo for individual non-display, still not a Telegram redistribution right). Budget Databento or Polygon Futures **on top**. This evaluation’s verdict: **do not buy**.
